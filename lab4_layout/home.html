Mengenal CSS Layout

CSS Layout membantu mengatur posisi dan ukuran elemen pada halaman web. Pada praktikum ini, layout disusun dengan semantic HTML dan CSS float. Properti clear digunakan agar elemen berikutnya tidak berada di samping elemen yang masih mengambang.

Mengapa HTML Semantik Penting?

Elemen semantik menjelaskan fungsi setiap bagian halaman. Struktur yang jelas membantu pemeliharaan kode, aksesibilitas, dan pemahaman dokumen oleh browser maupun teknologi pendukung.
