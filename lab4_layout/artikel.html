Artikel Praktikum

Catatan singkat mengenai materi CSS Layout.

Box Model CSS

Setiap elemen HTML dapat dipahami sebagai kotak yang terdiri dari content, padding, border, dan margin. Pengaturan keempat bagian ini memengaruhi ukuran serta jarak elemen.

Float dan Clear

Properti float memungkinkan elemen mengalir ke sisi kiri atau kanan. Properti clear mengatur agar elemen tidak ditempatkan di samping elemen yang sedang mengambang.

Semantic HTML

Elemen seperti header, nav, main, article, aside, dan footer memberi makna pada struktur halaman sehingga kode lebih mudah dibaca dan dikelola.
